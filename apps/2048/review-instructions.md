# 2048 게임 — Review 단계 지침

## 목표

Build 단계에서 구현된 `/apps/2048/` 게임이 `spec.md`대로 실제로 정상 동작하는지 브라우저에서 검증하고, 문제가 있으면 직접 수정한다.

## 범위 (중요)

- 검증 대상: `D:\claudecode_exam\my-blog\apps\2048\index.html`, `style.css`, `game.js`
- 문제를 발견해 수정할 때도 이 세 파일 안에서만 수정한다. 블로그 루트의 다른 파일(index.html, css/, js/, posts/, CLAUDE.md 등)은 절대 건드리지 않는다.
- 산출물로 `D:\claudecode_exam\my-blog\apps\2048\review.md`를 작성한다.

## 검증 절차

1. 먼저 `spec.md`를 읽어 원래 설계를 파악한다.
2. 로컬 정적 서버로 `/apps/2048/index.html`을 브라우저에서 연다 (예: `npx live-server` 를 `D:\claudecode_exam\my-blog` 루트 또는 `apps/2048` 디렉터리에서 실행하거나, 사용 가능한 프리뷰 도구로 해당 경로를 연다).
3. 브라우저 콘솔에 에러가 없는지 확인한다.
4. 방향키(위/아래/좌/우)로 타일이 밀리고, 같은 숫자끼리 합쳐지는지 확인한다. 한 번의 이동에서 `2 2 2 2`가 `8`이 아니라 `4 4`가 되는지 등 병합 규칙이 올바른지 코드/동작으로 확인한다.
5. 점수판이 병합 시 올라가는지, 새로고침 후에도 최고 점수(BEST)가 유지되는지(localStorage) 확인한다.
6. 이동해도 보드에 변화가 없는 방향으로 눌렀을 때 새 타일이 생기지 않는지 확인한다.
7. 승리(2048 타일) 및 패배(더 이상 이동 불가) 상황이 코드상 올바르게 처리되는지 확인한다 (직접 2048까지 플레이하기 어렵다면 로직을 코드 리뷰로 검증해도 된다).
8. 브라우저 창 크기를 모바일 폭(예: 375px)으로 줄여 레이아웃이 깨지지 않는지, 가로 스크롤이 생기지 않는지 확인한다.
9. 재시작 버튼이 정상 동작하는지 확인한다.
10. 발견한 문제는 세 파일 안에서 직접 수정하고, 수정 후 다시 확인한다.

## review.md에 포함할 내용

- 검증한 항목과 결과 (통과/실패, 실패 시 원인)
- 발견해서 수정한 문제 목록 (있다면)
- 수정하지 않고 남겨둔 사소한 이슈나 개선 여지 (있다면, 우선순위 낮음으로 표시)
- 최종 결론: 배포(Embed 단계 진행) 가능 여부

## 완료 조건

- `review.md` 작성 완료.
- 발견된 문제는 가능한 범위 내에서 수정 완료.
- 지정된 세 파일과 review.md 외에는 어떤 파일도 생성/수정하지 않는다.
