이 사이트는 `prefers-color-scheme` 미디어쿼리를 기본으로 다크 모드를 지원하고, 우측 상단 토글 버튼으로 직접 전환할 수도 있습니다. 선택한 테마는 `localStorage`에 저장되어 재방문 시에도 유지됩니다.

## 반응형 레이아웃

- 본문 폭을 제한해 가독성을 높였습니다.
- 코드 블록은 `overflow-x: auto`로 처리해 좁은 화면에서도 페이지 전체가 가로로 밀리지 않습니다.
- 이미지는 `max-width: 100%`로 제한됩니다.

```css
.container {
  max-width: 760px;
  margin: 0 auto;
}
```

> 작은 화면에서도, 큰 화면에서도 읽기 편해야 좋은 블로그입니다.
